## 1. 什么是 X-HEEP？

X-HEEP（eXtensible Heterogeneous Energy-Efficient Platform）是一个**基于 RISC-V 指令集的微控制器（MCU）**，用 SystemVerilog 硬件描述语言编写。

它和我们熟悉的 ARM Cortex-M 系列 MCU（如 STM32）在**功能定位**上类似——都能跑 C 程序、控制 GPIO、驱动 I2C/SPI/UART 外设、响应中断。但有两个根本区别：

| | ARM Cortex-M MCU（如 STM32） | X-HEEP |
|---|---|---|
| 指令集 | ARMv6-M / ARMv7-M（私有） | RISC-V RV32IMC（开放） |
| 硬件形态 | 一块成品芯片 | 一份 RTL 源代码（你可以改） |
| CPU 核心 | ARM 设计（黑盒） | CV32E40P / CV32E40X（开源 RTL） |
| 扩展方式 | 芯片引脚 + 外部电路 | 在 RTL 中直接添加加速器 IP |

**核心价值**：X-HEEP 提供了一套完整的、工业级验证的 MCU 平台（CPU、总线、DMA、中断、外设、调试），你可以**专注于添加自己的硬件加速器**，而不需要从零搭建 MCU。

### 1.1 典型应用场景

```
┌──────────────────────────────────────────────┐
│                  X-HEEP MCU                   │
│                                               │
│  ┌─────────┐   ┌──────┐   ┌──────────────┐  │
│  │CV32E40P │   │ RAM  │   │ 你的加速器     │  │
│  │ RISC-V  │   │ 64KB │   │ (矩阵乘法/FFT/ │  │
│  │  CPU    │   │      │   │  AI推理/密码)  │  │
│  └────┬────┘   └──┬───┘   └──────┬───────┘  │
│       └───────────┼──────────────┘           │
│                   │  OBI 总线                  │
│       ┌───────────┼──────────────┐           │
│  ┌────┴───┐  ┌────┴───┐  ┌──────┴──────┐    │

│  └────────┘  └────────┘  └─────────────┘    │

```

- **TinyML / 边缘 AI**：添加神经网络推理加速器，在 MCU 上跑 AI 模型
- **传感器融合**：添加 DSP 加速器，实时处理多传感器数据
- **安全应用**：添加 AES/SHA 硬件加密引擎
- **学术研究**：研究异构计算架构、新型加速器设计、低功耗策略

## 2. RISC-V 在 MCU 领域的生态

### 2.1 RISC-V 是什么？

RISC-V 是一个**开放、免费的指令集架构（ISA）**，由加州大学伯克利分校于 2010 年发起。

关键特征：
- **开放标准**：任何人都可以免费使用、实现、扩展
- **模块化**：基础整数指令集（RV32I/RV64I）+ 可选扩展（M=乘法、C=压缩指令、F=单精度浮点...）
- **可扩展**：预留了自定义指令空间，允许添加专属指令

### 2.2 RISC-V MCU 生态图谱

```
开源 RISC-V MCU 项目：

┌─────────────────┬──────────────────┬─────────────────────┐
│   项目          │    核心 CPU       │     特点             │
├─────────────────┼──────────────────┼─────────────────────┤
│ X-HEEP (EPFL)   │ CV32E40P/X/CVE2  │ 可配置、加速器友好    │
│ PULPissimo (ETHZ)│ RI5CY/Zero-riscy │ X-HEEP 的前身       │
│ OpenTitan (Google)│ Ibex            │ 安全 SoC，Google 背书 │
│ SERV            │ SERV (bit-serial)│ 世界最小的 RISC-V CPU │
│ VexRiscv        │ VexRiscv (FPGA)  │ SpinalHDL 实现       │
└─────────────────┴──────────────────┴─────────────────────┘

商业 RISC-V MCU：
- ESP32-C3/C5/C6（乐鑫）
- CH32Vxxx（沁恒微电子）
- GD32VF103（兆易创新）
```

X-HEEP 的定位：**面向研究和定制化设计**。它不是一颗固定功能的芯片，而是一个"MCU 模板"，你可以按需裁剪外设、更换 CPU、添加加速器。

## 3. X-HEEP 的技术渊源

X-HEEP 不是从零开始的项目，它站在三个成熟开源项目的肩膀上：

### 3.1 PULP-Platform（ETH Zurich / University of Bologna）

X-HEEP 的"骨架"：

```
PULP-Platform 贡献给 X-HEEP 的模块：
├── OBI 总线协议（Open Bus Interface）
├── Register Interface（寄存器代码生成工具 regtool.py）
├── GPIO 外设
├── RISC-V Debug Module（JTAG 调试）
├── common_cells（通用 RTL 基础库）
├── AXI 互联
└── FPU（浮点单元）
```

PULP-Platform 是欧洲 RISC-V 生态的核心项目之一，X-HEEP 的创始团队来自 EPFL 的 ESL 实验室，与 ETH Zurich 的 PULP 团队有长期合作。

### 3.2 OpenTitan（lowRISC / Google）

X-HEEP 的"外设库"：

```
OpenTitan 贡献给 X-HEEP 的模块：
├── UART
├── SPI Host
├── I2C Host
├── RV Timer
├── PLIC（平台级中断控制器）
└── regtool.py 上游（寄存器生成工具）
```

OpenTitan 是 Google 主导的开源安全 SoC 项目，其外设 IP 经过严格的验证流程，质量可靠。

### 3.3 OpenHW Group

X-HEEP 的"大脑"：

```
OpenHW Group 贡献给 X-HEEP 的模块：
├── CV32E40P — 4 级流水线 RISC-V CPU（RV32IMC）
├── CV32E40X — CV32E40P + XIF 协处理器接口
└── CVE2      — 2 级流水线 RISC-V CPU（面积更小）
```

OpenHW Group 是一个非营利组织，专注于开源 RISC-V 处理器的开发和验证。CV32E40P 是其旗舰 MCU 级核心，已在多款芯片中流片验证。

### 3.4 技术关系图

```
    PULP-Platform                OpenTitan              OpenHW Group
   (ETHZ / UniBO)            (lowRISC / Google)        (非营利组织)
         │                          │                       │
         │ OBI 总线                 │ UART/SPI/I2C          │ CPU 核心
         │ 寄存器接口               │ Timer/PLIC            │ CV32E40P/X
         │ 调试模块                 │ 寄存器工具链           │ CVE2
         │ GPIO                     │                       │
         └──────────────┬───────────┘───────────────────────┘
                        │
                        ▼
                   ┌─────────┐
                   │ X-HEEP  │  ← EPFL ESL / UPM CEI / POLITO VLSI
                   │         │    整合 + MCU 顶层 + 电源管理
                   │         │    + DMA 子系统 + 加速器框架
                   └─────────┘
```

## 4. 项目顶层结构速览

```
x-heep/
├── README.md              ← 项目介绍、引用信息
├── core-v-mini-mcu.core   ← FuseSoC 顶层描述文件
├── Makefile               ← 顶层 Makefile
│
├── hw/                    ← ★ 硬件 RTL 源代码
│   ├── core-v-mini-mcu/   ← MCU 顶层 + 各子系统
│   ├── ip/                ← X-HEEP 自研 IP（DMA、电源管理等）
│   ├── ip_examples/       ← 加速器集成参考示例
│   ├── vendor/            ← 第三方 IP（PULP、OpenTitan、OpenHW）
│   ├── fpga/              ← FPGA 顶层 wrapper 和约束
│   ├── asic/              ← ASIC 实现（SkyWater 130nm）
│   ├── simulation/        ← 仿真用 wrapper（SRAM、pad）
│   └── system/            ← 系统级模块（pad ring 等）
│
├── sw/                    ← ★ 软件（固件 + SDK）
│   ├── applications/      ← 50+ 示例应用
│   ├── device/lib/        ← HAL 驱动库
│   ├── device/target/     ← 启动文件、中断向量表
│   ├── linker/            ← 链接脚本
│   ├── freertos/          ← FreeRTOS 移植
│   └── CMakeLists.txt     ← 软件构建系统
│
├── configs/               ← Hjson 硬件配置文件
├── util/                  ← 代码生成工具（xheep_gen）
├── tb/                    ← 仿真 testbench
├── test/                  ← 测试脚本
├── docs/                  ← 文档源文件（.rst）
└── scripts/               ← 辅助脚本
```

**你现在不需要理解每个目录的细节**——我们在后续课程中会逐个深入。本课只需要建立"这里有什么"的大致印象。
